**资金信号体系（用于状态切换条件分析，以状态为中心反查资金形态）**

1. 股指期货：`basis_z`基差（期货态度）、持仓水平、持仓绝对 / 相对变化（持仓放大代表市场敞口 / 参与度提升，实验内部口语叫分歧度，**数据定义禁止命名为分歧度**）
2. ETF 份额：宽基 ETF 份额绝对变化、变化率 → 中长期配置资金态度
3. 两融：两融余额绝对变化、变化率 → 杠杆资金
4. 成交额：成交额相对 20 日均值 → 场内交易活跃度

**核心实验逻辑**

1. HMM 只使用**过滤概率 P (Sₜ | X₁:ₜ)**，禁止平滑概率（规避未来泄露）；训练测试 7:3 时间切分，标准化只用训练集统计量。
2. 资金信号全部做**250 日滚动 Z‑score 归一化**；分档使用滚动 250 日 1/3、2/3 分位，禁止全局全样本分位。
3. 条件转移：\(P(S_{t+h}=j | S_t=i, M_t=m)\)，对比基准\(P(S_{t+h}=j|S_t=i)\)，用 lift（差值）衡量资金对状态跳转的抬升 / 压制；
4. 统计校验：block‑bootstrap 块 bootstrap，时间分段，三级证据评级（探索性 / 候选 / 稳健）；小样本 n 阈值过滤。
5. 评估指标：ES5 (5% 分位未来收益)、MAE、MDD；逐年稳健、非重叠窗口复核；约束：最小状态占比≥5%，中位状态持续≥5 天，ES5 极差≥1%。

# 重要设计约束汇总（注释已经写进代码，方便后续迭代）

1. **无未来泄露铁律**
   - HMM 只用过滤概率`P(Sₜ|X₁:ₜ)`，**禁用平滑概率**；
   - 标准化统计量、分档阈值全部使用滚动 / 训练集，禁止全局全样本分位；
   - OOS 首日先验使用训练集最后一步过滤后状态乘以转移矩阵，不使用训练集 pi。
2. **命名纪律：持仓量≠分歧度**：持仓量只代表参与度、敞口，实验文档内口头可以说分歧，**变量名、字段名绝对禁止叫分歧度**。
3. **模型固定配置**
   - 短价格：Student‑t K=3；短波动 Gaussian K=3；长价格 Student‑t K=2；**删除中长期波动模型**
4. **资金分析仅针对短周期 3×3 九宫格；中长期只有价格一维，不做资金条件转移**
5. 统计三级证据：探索性 → 候选 → 稳健；稳健要求：前后分段 lift 同号，两段 CI 都不含 0，**晚期样本复现**。
6. 小样本直接丢弃，n 阈值写在 config 统一管理，不要散落在各个函数。
